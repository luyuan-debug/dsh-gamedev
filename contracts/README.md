# 配置结构与功能约定

本目录供修改插件和编写测试的开发者查阅。普通安装请使用 [安装指南](../docs/SETUP.md)。

| 文件 | 用途 |
| --- | --- |
| `settings.schema.json` | 设置数据模型，供说明与测试使用；不代表当前界面已支持全部枚举项 |
| `settings.example.json` | 数据模型示例；不是可直接导入的 DSH YAML 配置 |
| `product.json` | 预设名称、默认行为、功能范围和测试计划的位置 |

`product.json` 中的平台目标和功能清单用于定义开发与测试范围，不是已支持功能列表。当前版本实际验证的内容见 [测试说明](../docs/VERIFICATION.md)。文件名和字段名供代码、检查器及已有配置使用，修改时需要同步检查相关调用。

DSH 实际使用的是扁平配置字段，格式和支持项以 [高级配置](../docs/INSTALL.md#手动配置文件) 为准。
