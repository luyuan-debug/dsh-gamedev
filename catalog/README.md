# 工具与参考资料目录

这个目录列出编辑器连接、可选工具和开发参考，供维护者与开发助手查阅。目录中的条目不会自动安装，也不表示插件已经集成它。

| 文件 | 内容 |
| --- | --- |
| `tools.json` | 工具用途、使用条件、许可说明与来源编号 |
| `pinned-bridge-tools.json` | 固定版 Godot Editor MCP 的工具名称和参数说明 |
| [SOURCES.md](SOURCES.md) | 来源编号对应的项目和文档链接 |

当前编辑器连接使用 Godot Editor MCP **2026.10.20.1**。设置页可选择已安装的 GDScript Toolkit、ImageMagick 和 FFmpeg；其他条目作为现有项目的参考或后续评估对象，不是默认功能。

`runtimeStatus: NOT_RUN` 表示目录条目本身不记录执行结果。发行版的实际测试结果见 [测试说明](../docs/VERIFICATION.md)。
